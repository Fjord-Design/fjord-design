# XER-119 accessibility verification

Branch: `codex/xer-119-accessibility`. Evidence collected on 27 October 2026. This assessment is incomplete.

## Automated contrast evidence

`mise run accessibility:report` writes `dist/accessibility-contrast.json`, with exact token names, colour values, thresholds and unrounded sRGB and HEX ratios. It checks 143 pairs in Night, 144 in Day and 143 in Aurora for each of Fjord and Fern. Each pair is checked in both source sRGB and 8-bit HEX, for 1,720 comparisons. All recorded pairs passed their configured thresholds at the time of this check.

The closest pair to its configured threshold in both identities is comment text on the base surface in Night: 7.51709:1 against 7.5:1. The weakest margin in Day is the same pair: 5.08041:1 against 5:1. Aurora's weakest margin is bright black terminal text on the base surface: 4.53467:1 against 4.5:1. The stored report retains full precision; rounded values here are for reading only.

The thresholds include 4.5:1 for ordinary text, 3:1 for applicable interface indicators and stricter Fjord requirements for comments. [WCAG text contrast](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) specifies exceptions for large text, inactive controls, decoration and logos. [WCAG non-text contrast](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html) covers information needed to identify active controls and their states. These token comparisons do not prove that every rendered component uses a checked pair or that its visual boundary is identifiable.
