# XER-111 verification

Branch: `codex/xer-111-choice-controls`. Local verification on 27 October 2026.

| Acceptance criterion | Evidence |
| --- | --- |
| Checkbox, radio and switch states | Native Checkbox supports checked, unchecked and client-hydrated indeterminate states. RadioGroup uses a fieldset, legend and one shared name. Switch is a native checkbox with switch semantics and a stable label. |
| Anatomy and token mapping | `docs/components/choice-controls.md` records variants, interaction states, semantic roles, form behaviour and limitations. The shared stylesheet supports Night, Day, Aurora and other identities. |

A submit produced frequency `weekly`, agreement `yes` and notifications `on`. A mixed checkbox changed to checked and then unchecked. |
| Catalogue and controls | Components/Choice controls demonstrates all three controls, mixed and disabled states, native validation and form output. Server-rendering tests verify semantics, required and disabled attributes, error association, empty options and duplicate values. |

No new dependency was added. The Svelte package is 0.4.0; token contract 0.3.0 is unchanged.
