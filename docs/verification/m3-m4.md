No new runtime or library was installed on the host; the extracted-archive check used the previously authorized locked JavaScript dependency set. Native Neovim is explicitly excluded from CI rather than being silently skipped as a pass.

## Native observations

WezTerm `20260716-195552-76b606ec` ran in isolated XWayland windows inside the KDE Wayland session. Fjord, Work and Gaming each passed Night, Day and Aurora: all expected normal/bright palette pixels, truecolour sample and native selection text were present. The fixture also shows cursor, OSC 8 link, signed diff/error cues and prompt context. Hyperlinks were not opened. Only owned windows were captured/closed. Nine Lua configuration checks used an execution marker after preservation assertions; exit status alone is insufficient because WezTerm can report a config error and fall back while returning success. An early helper failure using unavailable sandbox `debug` was fixed with an explicit scheme-directory argument; only the subsequent marker/native results count.

KDE Plasma 6.8.2 / Qt 6.12.0 / Breeze / Noto Sans produced nine isolated QWidget previews. Native QPalette values matched each generated scheme; the input retained focus and selected text. Checked `kdeglobals`, `kwinrc` and `plasmarc` hashes were unchanged. Rich-text links and style-derived inactive/disabled/focus details can differ from mapped palette values; the POC deliberately stops short of production desktop support.

An exact image comparison between two native capture runs found a small caret-phase difference in one image. The Linux-only preview now uses a steady application caret; two subsequent runs matched all 18 before/after PNGs exactly. This produces a candidate visual baseline on this host, not proof of compatibility on another host. The application cursor control follows the [Qt QApplication API](https://doc.qt.io/qt-6/qapplication.html#cursorFlashTime-prop); the preview does not set a system appearance preference.
