## Automated verification

Run `mise run ci` and `mise run test:clean`. Regression tests cover unsafe targets, breakpoints, density, layers, timing and intermediate overrides; corrupted or active SVG content; missing licences; stale generated data; and source-file output protection. Equivalent rem/time units are accepted. The independent consumer checks foundation CSS and original icon/licence bytes. Type probes reject meaningful icons without labels.

Both workflows passed, including a frozen install in a source-only temporary copy. The suite contains 109 Python tests; Svelte reports zero errors and warnings. All 400 DTCG tokens per mode, 412 contrast pairs, 102 platform values and 84 local documentation links pass. TypeScript rejects an unnamed meaningful icon in both library source and the separate archive consumer. Existing colour and typography values, font preferences and SVG brand assets retain their approved values. No new JavaScript dependency was installed.

## Browser verification

The specimen is `dist/foundations.html`. Comfortable and compact modes both rendered 15px body text with 24px line height. Gap/panel padding changed from 16/20px to 12/12px; the primary control changed from 40.5px to 34px while keeping its label visible.

All six combinations of Night/Day/Aurora and comfortable/compact density passed at a 390px viewport with 200 percent text. The document client and scroll widths were both 375px; body text was 30px with 48px line height. Long actions grew in height and retained their full text.

Enter activated Create theme and produced its status message. Space expanded the guidance section while keeping focus on the trigger with a visible 2px outline. The icon-only dismiss action has its name on the button. The static Svelte icon story exposes one meaningful image named Information; adjacent decorative icons do not duplicate labels.

With reduced-motion and forced-colours preferences emulated together, the loading/reveal animation names were none, transitions were 0s, panel shadows disappeared and solid borders/focus remained. Loading text stayed visible and disclosure content remained operable. With coarse-pointer emulation, the primary action and icon-only action measured 44px high; the icon-only action was 44px wide. Preference/touch emulation and the viewport override were reset after testing.

Screenshots and measured results are saved under `dist/verification/xer-106-*`. These are local Chromium checks, including system-preference emulation; they do not establish native Windows high-contrast or screen-reader coverage.
