# XER-116 verification

Branch: `codex/xer-116-token-export`. Local verification on 27 October 2026.

The exporter composes and validates the same token source before emitting DTCG, resolved JSON, CSS and WezTerm TOML. Automated tests cover all three modes, the Fern override, deterministic output, required role and alias failures, CSS name collisions, source protection, and the cursor, selection and 16 ANSI mappings. The export guide describes precision, colour fallback, name mapping and installation.

WezTerm `20240203-110809-5046fc22` on macOS `26.7.1` loaded each mode's generated TOML through its own `wezterm.color.load_scheme` in an isolated temporary configuration. The test used `show-keys` and did not change the user's settings.

Native visual checks for ANSI, cursor, selection and prompt context were incomplete at this check while the Mac was locked. XER-116 was subsequently closed through [owner acceptance of the local MVP](xer-120.md), which records a Linux WezTerm check and the remaining macOS/Fern limits.
