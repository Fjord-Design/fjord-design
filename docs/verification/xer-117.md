# XER-117 verification

Branch: `codex/xer-117-catalogue`. Local verification on 27 October 2026.

The Fjord/Explore story provides Night, Day, Aurora and System modes, Fjord and Fern identities, compact and comfortable density, a settings example, semantic colour samples, all typography roles, a code example and a token inspector. The inspector displays source, original value, resolved value and a copyable CSS custom property. Other component stories cover the 23 MVP components and their states. Brand images use the supplied Day and Night SVG variants.

`mise run catalogue:build` generates token data from validated compositions. `test_catalogue.py` compares every displayed token and source to its actual composition for both identities and all three modes, and checks reproducibility. CI checks Svelte types and builds the static Storybook.

The in-app Chromium browser now verifies mode, identity and density switching, token filtering including no matches, copying the exact CSS reference, and the correct Day/Night brand variant. Keyboard Tab from Save settings reached the token filter. System switched to Day and Night when the emulated system preference changed.

At a 320px viewport with a 200% root font size, all 12 combinations of three modes, two identities and two densities retained document width. The browser's scrollbar left a 305px content area; document and scroll widths both remained 305px. The check found an intrinsic grid width that let a long token control expand the page. An explicit shrinkable stack column and local minimum-width rules corrected it. Forced colours and reduced-motion emulation also retained the page width. Local evidence: `dist/verification/xer-117-reflow.json` and `dist/verification/xer-117-catalogue-day.png`.

The full release browser matrix and screen reader checks remain open. XER-117 remains in progress.
