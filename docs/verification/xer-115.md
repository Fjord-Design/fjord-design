# XER-115 verification

Branch: `codex/xer-115-typography-code`. Local verification on 27 October 2026.

Typography renders a caller-selected native text element with a shared type role. Kbd renders native keyboard markup. CodeBlock preserves and copies the original source and rejects syntax segments that do not reproduce it. Syntax colours use the validated base surface; comments and keywords use the standard slanted Cascadia italic. The component guide describes token mapping, localization and clipboard failure behavior. Storybook provides Night, Day, Aurora and Fern examples.

`mise run test:type-components` checks rendered headings, keyboard markup, escaped source, the named scrolling region, status semantics and segment validation. CI checks the Svelte types, packaged consumer, generated styles and catalogue build.

Clipboard access and feedback, visual syntax and ligatures, horizontal scrolling, text zoom and screen reader announcements still need browser and assistive-technology checks. The Mac was locked during implementation, so XER-115 remains in progress.
