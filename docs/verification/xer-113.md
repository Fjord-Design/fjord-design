# XER-113 verification

Branch: `codex/xer-113-dialog-alert-tooltip`. Local verification on 27 October 2026.

| Acceptance criterion | Evidence |
| --- | --- |
| Dialog, alert and tooltip | Dialog uses native modal behaviour and a visible name, optional description and close action. Alert provides static, polite or assertive semantics. Tooltip links supplementary text to its trigger. |
| Anatomy and tokens | `docs/components/dialog-alert-tooltip.md` records anatomy, semantics, roles, variants, states and limits. The shared stylesheet uses Fjord semantic values. |
| Interaction | Chromium keyboard checks verified modal opening, focus cycling in both directions, Escape and focus return. Rapid close and reopen worked for Escape and the close button. Tooltip opened on focus and hover, stayed open over its content and closed on Escape or pointer exit. Synthetic touch pointer events verified opening, a second touch closing even while focus remained, and outside dismissal. The alert's mounted status region updated its text. |
| Catalogue and checks | Components/Dialog Alert Tooltip demonstrates the components. Verification/Tooltip touch events supplies a synthetic event fixture. Server rendering tests verify modal naming, live-region roles and tooltip description links. |

No new library dependency was added. Svelte package 0.6.0 uses token contract 0.3.0.

Live-region roles and updates were inspected, but spoken announcements and the complete release browser matrix remain in XER-119. Embedded frames and closed shadow roots require their own focus handling.
