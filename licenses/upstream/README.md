| --- | --- |

| `rolldown-1.2.15.txt` | [Rolldown v1.2.15](https://github.com/rolldown/rolldown/blob/v1.2.15/LICENSE) |

The Storybook notice covers the Storybook packages in the inventory at 10.6.3. The esbuild, resolver and Rolldown notices also cover their platform binding packages at the listed versions. The inventory includes build tools as well as code in the catalogue. It is not a finished inventory of the code actually distributed in the Storybook build. Additional source verification is still needed for the packages without notices, including `@oxc-parser/binding-darwin-arm64`, `is-reference` and `locate-character`. Complete the distribution review before accepting the release.
