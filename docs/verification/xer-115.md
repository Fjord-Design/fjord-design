# XER-115 verification

Branch: `codex/xer-115-typography-code`. Local verification on 27 October 2026.

Typography renders a caller-selected native text element with a shared type role. Kbd renders native keyboard markup. CodeBlock preserves and copies the original source and rejects syntax segments that do not reproduce it. Syntax colours use the validated base surface; comments and keywords use the standard slanted Cascadia italic. The component guide describes token mapping, localization and clipboard failure behavior. Storybook provides Night, Day, Aurora and Fern examples.

`mise run test:type-components` checks rendered headings, keyboard markup, escaped source, the named scrolling region, status semantics and segment validation. CI checks the Svelte types, packaged consumer, generated styles and catalogue build.

Chrome 156.0.8078.48 on macOS 26.7.1 was checked in Night, Day, Aurora and Fern. The copied source matched the displayed characters, including the long line. Copy failure displayed a useful message. The code region remained keyboard-focusable and scrolled separately at 320 CSS pixels. A 200% root font size retained the controls without document overflow. The comment used the bundled Cascadia Code italic face with handwritten alternates off; the ligature setting could also be disabled.

The check exposed two named regions around the code and a browser default that replaced Cascadia with a generic monospace face. The code now has one named region and inherits the intended font. Narrow layouts also retain more content width at enlarged text sizes. Screen reader announcements and the full release browser matrix remain open, so XER-115 stays in progress.
