# XER-112 verification

Branch: `codex/xer-112-card-separator-tabs`. Local verification on 27 October 2026.

| Acceptance criterion | Evidence |
| --- | --- |
| Card, separator and tabs | Card uses an opaque surface and restrained depth. Separator distinguishes decorative and semantic horizontal and vertical forms. Tabs visibly identify the selected panel. |
| Anatomy and tokens | `docs/components/cards-separators-tabs.md` documents semantics, roles, variants, states and limitations. The shared stylesheet uses Fjord semantic values. |
| Navigation and reflow | In Chromium, each tab's `aria-controls` and each panel's `aria-labelledby` resolved to its partner. Manual arrows moved focus without selection; Enter selected; Tab then moved to the active panel. Disabled tabs were skipped. Vertical automatic selection followed arrow focus. A draft input retained its value after switching away and back. At a measured 390px viewport, the page had 375px client and scroll widths while the horizontal tablist scrolled independently. End focused and revealed the final tab. |
| Catalogue and checks | Components/Card Separator Tabs demonstrates both activation modes, both orientations, a disabled tab, long labels and both separator meanings. Server-rendered tests verify card and separator markup, selection, pairings and invalid item sets. |

`mise run ci` and `mise run test:clean` passed locally: 120 Python tests, server-rendered layout checks, Svelte and TypeScript checks, Storybook build, separate packaged consumer and stylesheet, deterministic outputs and 92 local links. No new library dependency was added. The Svelte package is 0.5.0 and the token contract remains 0.3.0.

Forced-colour emulation revealed that the browser painted a black rectangle over selected tab text. Using system highlight colours with `forced-color-adjust: none` on the selected tab preserved visible text and focus. Native assistive-technology and full release browser coverage remain in XER-119.
