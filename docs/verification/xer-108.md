## Scope of this result

XER-108 defines roles and verifies the code specimens. Native terminal configuration, application versions, actual SGR interpretation, cursor/selection integration and installation are part of XER-116. No terminal application is declared supported by this browser check. Font files, a general syntax highlighter, screen-reader testing and a full accessibility audit are not included. The GitHub workflow is configured to run checks, token builds and the preview build; it has not run remotely.
