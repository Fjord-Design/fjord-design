# XER-120 MVP candidate

This is a local candidate for MVP `0.1.0`, not an accepted release. The token contract is `0.3.0`; the Svelte package has its own version in `svelte/package.json`.

Run `mise run release:prepare` to build the token exports, Svelte reference, Storybook and contrast report and assemble `dist/release/fjord-mvp-0.1.0-candidate.zip`. The archive contains those outputs, the source project, component and theme documentation, brand assets, Fern source example, MIT licence and changelog. Its `manifest.json` records SHA-256 hashes of the included files. The archive is local and the task does not publish it.

The source repository's [theme guide](../theme-guide.md) explains clean-checkout setup, consumption and adaptation. The [component inventory](../components/inventory.md) lists the 23 MVP components. Fonts and icons in the Svelte output include their original notices. The archive also collects installed dependency metadata and available root licence or notice files under `third-party-notices/`. Some installed packages provide no root licence file. Four exact-version upstream notices have been retained under `licenses/upstream/`; the remaining gaps are listed there. The inventory includes build dependencies and is not proof of which code is bundled; Storybook’s third-party distribution notices still need a complete licence review before distribution.

Acceptance remains open: XER-114 through XER-119 require the recorded browser, native terminal and assistive-technology checks. XER-120 also requires the user's visual assessment in a bright office and a dark room. Do not treat the candidate or automated checks as release acceptance.
