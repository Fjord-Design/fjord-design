# XER-118 verification

Branch: `codex/xer-118-theme-guide`. Local verification on 27 October 2026.

The theme guide describes setup, layer order, the Fern identity, all mode choices, scoped Svelte integration, exports, adapter limits, contrast and upgrades. Fern is applied to the same component code in the catalogue, and switching identity restores Fjord. The scoped identity generator validates all modes and rejects non-colour changes that it cannot represent.

`test_theme_css.py` compares generated scoped values with the actual composition for all modes, tests System selectors and invalid input, and runs both documented CLI commands in a temporary directory. The clean project test runs the project checks and builds the static catalogue.

The guide's two export commands were rerun successfully. The clean project check also passed with the current source, dependencies and catalogue build. In the in-app browser, Fern changed the shared component colours in Night, Day and Aurora, and choosing Fjord restored the default source bindings. The token inspector showed the matching theme alias and resolved value. Native selection controls and keyboard Tab navigation were checked, and the catalogue retained document width at 320px with enlarged root text across both identities and densities.

These checks complete the theme-guide criteria. Native terminal appearance, the complete browser matrix and screen reader testing retain their own acceptance tasks in XER-116, XER-117 and XER-119.
